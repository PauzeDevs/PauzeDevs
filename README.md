# 03 — FLAGSHIP

## 🌦️ PAUZEWEATHER

**Weather, rebuilt around speed, visualization and AI.**

PauzeWeather combines real-time weather data with an interactive map, radar and an AI assistant in one modern experience.

### What I built

- 🌡️ Real-time weather conditions
- 🕐 Hourly forecasts
- 📅 Multi-day forecasts
- 🌧️ Precipitation data
- 📡 Interactive weather radar
- 🗺️ High-zoom weather maps
- 💨 Wind information
- ☀️ UV information
- 📍 Location search
- 🤖 Pauze AI
- ⚡ Optimized API loading
- 📱 Mobile-focused UI

**Goal:** make weather information feel like a product instead of a spreadsheet of numbers.
